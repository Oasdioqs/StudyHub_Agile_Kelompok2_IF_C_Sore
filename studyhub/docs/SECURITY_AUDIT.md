## Recommended Next Steps

1. **Rate Limiting** — Tambah middleware rate limit untuk `/api/auth/*`:
   ```typescript
   // Contoh: pakai Vercel Edge Rate Limiting atau in-memory Map
   const rateMap = new Map<string, { count: number; resetAt: number }>()
   
   function checkRateLimit(ip: string, limit = 5, windowMs = 15 * 60 * 1000): boolean {
     const now = Date.now()
     const entry = rateMap.get(ip)
     if (!entry || now > entry.resetAt) {
       rateMap.set(ip, { count: 1, resetAt: now + windowMs })
       return true
     }
     if (entry.count >= limit) return false
     entry.count++
     return true
   }
   ```

2. **Structured Logging** — Ganti `console.error` dengan structured logger (winston/pino)

3. **Dependency Audit** — Jalankan `npm audit --audit-level=high` secara rutin (sudah ada di CI)

4. **Secret Scanning** — Aktifkan GitHub Secret Scanning di repo settings

5. **CSRF Protection** — Verifikasi NextAuth CSRF token sudah aktif (default: yes untuk form actions)
